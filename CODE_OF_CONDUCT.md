# Code of Conduct / 行動規範

Keep discussion respectful, specific, and focused on improving Narabi. Do not post confidential documents, personal information, credentials, or exploit details in public issues. Security concerns must follow `SECURITY.md`.

Narabiに関する議論は、相互に配慮し、具体的で、改善に集中した内容にしてください。公開Issueへ機密文書、個人情報、認証情報、悪用可能な詳細を投稿しないでください。セキュリティ上の問題は`SECURITY.md`に従ってください。
