# Support / サポート

For reproducible bugs, use a GitHub issue after removing confidential material and personal information. Include the app version, OS version, device, input type, expected result, actual result, and minimal reproduction steps. For security-sensitive matters, follow `SECURITY.md`. Private contact when necessary: `mexenixi@gmail.com`. A response cannot be guaranteed.

再現可能な不具合は、機密情報と個人情報を除いたうえでGitHub Issueへ投稿してください。アプリ版、OS版、端末、入力形式、期待結果、実際の結果、最小の再現手順を含めてください。セキュリティ関連は`SECURITY.md`に従ってください。非公開連絡が必要な場合は`mexenixi@gmail.com`を利用できます。返信は保証されません。
