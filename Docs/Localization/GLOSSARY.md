# Narabi Localization Glossary / 用語集

## Narabi

The language-neutral product identifier. Do not translate it. Localized display names may differ.

## Project / プロジェクト

A saved collection of ordered pages, materials, and export settings.

## Page / ページ

One ordered item in a project. A page may come from a photo, scan, PDF page, text file, structured data, or supported document.

## Material tray / 素材欄

The area that holds imported items before or while users arrange them into the page order.

## Import / 取込み

Bring supported content into a project. Do not translate this as cloud upload.

## Export / 出力

Create or share PDF, JPEG, PNG, transparent PNG, or Photos output from arranged pages.

## Support purchase / 応援購入

An optional consumable In-App Purchase. It does not unlock features, increase storage, remove limits, or provide priority treatment.

## Original size / 元サイズ

Use the source dimensions without selecting a fixed output size.

## Custom size / カスタムサイズ

A width and height entered by the user.

## Hidden from preview and output / プレビューと出力から除外

The page remains in the project but is excluded from preview and generated output.
