# Document page import

Narabi reads basic text from DOCX, XLSX, and PPTX and lays it out as Narabi pages. Exact Office compatibility is intentionally not provided. Source files are not modified. Use PDF import when appearance must match.

## Progress and cancellation

Large PDF and document imports report file and page progress. Cancelling an import discards pages generated by the current import before they are committed to a project. Source files are never modified.

## Text encoding policy

Text import prioritizes explicit BOM declarations, then valid UTF-8. BOM-less UTF-16 is accepted only when null-byte distribution supports that interpretation. Shift_JIS and system encoding detection are attempted afterward. HTML uses document metadata when available.
