# Operations matrix

| Operation | Editor | Material tray | Deleted | Auto-save | Export effect |
|---|---:|---:|---:|---:|---|
| Reorder | Yes | Yes | No | Yes | Uses editor order |
| Move between areas | Yes | Yes | Restore only | Yes | Pages in the editor are eligible |
| Page editing | Yes | Move to editor first | No | On confirmation | Updates the editor page |
| Normal delete | Yes | Yes | Retained | Yes | Deleted pages are excluded |
| Hide | Yes | No | No | Yes | Hidden pages are excluded |
| Standard export | Yes | No | No | No | Uses selection or editor order |
| Composite | Yes | No | No | On save | Creates a composite result |
| AI reorder | Yes | No | No | On apply | Updates editor order after confirmation |
