# Supported import formats

## Images and PDF

- Common image formats readable on iPhone and iPad
- PDF

## Documents and text

- DOCX, XLSX, and PPTX through Sort & Done!’s own on-device page creation
- Plain text, TEXT, LOG, and Markdown
- CSV and TSV
- JSON, XML, YAML, HTML, and ICS

DOCX, XLSX, and PPTX are reorganized into the App’s own pages. This is not an Office-compatibility conversion, and exact layout, formatting, pagination, equations, shapes, charts, and embedded objects are not guaranteed.

Certain older Office or iWork documents may use one system-generated preview when iOS can create one. For a document whose appearance must be preserved, export it as PDF in its originating app before importing it.

## Import result reporting

When some selected items cannot be read, successfully created pages remain available and Narabi reports input, success, and failure counts. If every selected item fails, no empty project is created. Verification status is tracked in [ImportFormatVerification.md](ImportFormatVerification.md).
