# Import format verification matrix

This matrix records formats included in the supported product scope and separates code support from physical-device evidence.

| Format group | Runtime route | Product behavior | Verification |
|---|---|---|---|
| iOS-readable images, including JPEG and PNG | Image pipeline | One page per image | JPEG and PNG verified |
| PDF | PDFKit | One app page per readable PDF page | Two-page PDF verified |
| DOCX | On-device structured conversion | Narabi pages; Office fidelity not guaranteed | Japanese and English content verified |
| XLSX | On-device workbook conversion | One or more Narabi pages | Two sheets verified |
| PPTX | On-device slide conversion | One or more Narabi pages | Two slides verified |
| TXT, TEXT, LOG, Markdown | Text renderer | Paginated readable text | Japanese and English content verified |
| CSV, TSV | Delimited-text parser | Table-oriented pages | Japanese and English content verified |
| JSON, XML, YAML, HTML | Structured/text renderers | Readable pages | Japanese and English content verified |
| ICS | Calendar text renderer | Readable event page | Test event verified |
| Older Office or iWork fallback | iOS system preview when available | One convenience preview | Availability depends on the system preview generated by iOS; this format was not included in the version 1 physical-device sample set. |

The September 6, 2026 test produced 22 pages from the selected supported samples. The two-page PDF, two-sheet XLSX, and two-slide PPTX each preserved their additional page. The source documents were not modified.
